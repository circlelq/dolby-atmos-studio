# dolby-atmos-studio

一间"听、混、录"三能的客厅工作室建设蓝图：以真力有源监听为音箱基底，以杜比全景声为格式主线，从 Apple Music 欣赏起步，逐步长出混音和录音能力。

## 文档

[杜比全景声安装计划](杜比全景声安装计划.md) —— 总体蓝图，持续更新。包含：核心决策（天龙 AVR-X3900H / 真力 G 系列 / Audient ORIA）、分阶段路线、看片子系统、近期行动清单、装修预埋清单。

## 三条原则

1. **大脑先行**：解码/校正/低频管理是系统的灵魂，音箱只是执行者
2. **每一步独立可听、零浪费**：每只箱子买了就永远有位
3. **技能成本 > 设备成本**：让第一首歌和第一次 Audyssey 告诉你节奏
